操作手册

户型装修设计

在 2D 平面图上摆家具、拆墙、量尺寸、换地面，一键切到 3D 场景鸟瞰或漫游。也可以导入自己的 DXF 施工图，在自己的户型上做方案。

适用版本：dev_1022 分支（2026-10-22）尺寸单位：mm面积单位：m²

开始使用

整个应用就是一个 index.html 文件，不需要安装，也不需要构建。

  1. 用 Chrome、Edge、Firefox 或 Safari 的较新版本，直接打开 index.html。
  2. 如果浏览器限制本地文件，也可以在项目目录起一个静态服务器，再访问 http://localhost:8000：
    python3 -m http.server 8000
  3. 第一次进入 3D 场景需要联网，Three.js 从 jsDelivr CDN 加载。2D 平面和 DXF 导入不需要联网。

首次打开显示的是内置的三室两厅两卫户型，已经摆好一套示例家具。所有改动都会自动存在当前浏览器里，下次打开还在。

界面语言顶栏右侧的 简 繁 EN 切换简体中文、繁体中文和英文，选择会被记住。

布置家具

添加

从左侧家具库把家具拖到平面图上。触屏设备可以直接点一下家具库里的条目，家具会放在画面中央。家具必须放在地面上，拖到户型外面会提示「请拖到地面上」。

移动、旋转、改尺寸

  • 移动：在 选择 工具下拖动家具。方向键微调 10mm，按住 Shift 微调 100mm。
  • 旋转：拖动家具上方的圆点，默认按 15° 吸附，按住 Shift 可以任意角度。R 顺时针转 90°，Shift+R 逆时针。
  • 改尺寸：拖动右下角的方块。
  • 贴墙吸附：顶栏 贴墙吸附 打开时，家具靠近墙面会自动贴齐。

精确编辑

选中家具后，右侧面板可以直接输入名称、宽、深、中心 X / Y（mm）、旋转角度和颜色，并显示占地面积。下面的按钮是 旋转 90° 复制 置于顶层 置于底层 删除。

Ctrl+D 复制，Delete 或 Backspace 删除。清空布置 一次删掉所有家具，可以撤销。

测量与拆墙

测量

  1. 选 测量 工具，或按 M。
  2. 点起点，再点终点，图上会留下一条带长度（mm）的标注。靠近墙面时自动吸附到墙面；按住 Shift 锁定水平或垂直。
  3. 右侧面板的 清除测量 删掉所有测量线。

拆改墙体

  1. 选 拆改墙体 工具，或按 X。
  2. 点一段灰色墙体，标记为拆除（变成虚线框）；再点一次恢复。
  3. 右侧面板「拆除墙体」统计已拆除的总长度。

颜色含义：黑色是承重墙，不能拆；深灰是外墙，提示「不建议拆除」；浅灰是非承重墙，可以拆。打开顶栏 承重墙 图层，承重墙会显示为红色，便于查看。

3D 场景

点顶栏 3D 场景 或按 T 进入 3D，再按一次回到 2D。2D 里的所有改动（家具、拆墙、地面材料）都会同步到 3D。

鸟瞰模式

  • 桌面端：左键拖动旋转，右键拖动平移，滚轮缩放。
  • 触屏：单指旋转，双指缩放和平移。
  • 斜视 和 俯视 切换到预设的全屋视角；左侧房间列表点哪个房间就飞到哪个房间，全屋 回到整体视角。
  • 点选家具后可以直接在 3D 里拖动摆放，2D 平面同步更新。
  • 点击门可以开关。

漫游模式

点 漫游 进入第一人称视角。内置户型从入户门外出发；导入的户型从入户门外出发，没有识别出入户门时从第一个房间出发。

开关门看着门按 E（2.5 米以内）点门

显示选项

  • 全高墙 / 剖切墙：剖切墙把墙体切矮，便于从上方看清室内。进入漫游时自动切回全高墙。
  • 家具 房间名：显示或隐藏家具和房间标签。
  • 日照 滑块：调整时间，阳光方向和阴影随之变化。
  • 夜景：打开室内灯光。

导入 DXF 户型

可以把自己的施工图导入进来，替换内置户型。导入后，摆家具、拆墙、换地面、算造价、3D 漫游都和内置户型一样使用。

图纸要求

图层内容画法要求
WALL墙体双线画法，两条平行线的间距就是墙厚，间距需在 60–500 mm 之间。只支持水平和竖直的墙。
DOOR门通常是一个图块，含门扇线和开启弧。程序按开启弧判断铰点和开门方向。
WINDOW窗画在墙洞里的几条平行细线或窗图块。
TEXT房间名单行文字或多行文字，放在房间内部。文字所在的区域就以它命名。
  • 文件格式：ASCII 格式的 DXF。DWG 和二进制 DXF 不支持，请在 CAD 里另存为 DXF。
  • 图层名不区分大小写，wall 和 WALL 都可以。
  • 单位：按 DXF 文件头里的单位换算（英寸、英尺、毫米、厘米、米），没写单位时按毫米处理。
  • 中文编码：UTF-8 和 GBK 都能识别，老版本 CAD 导出的 GBK 文件房间名不会乱码。
  • 其他图层（家具、标注、填充等）全部忽略。

导入步骤

  1. 点顶栏 文件 ▾，选 导入 DXF 户型。
  2. 选择 .dxf 文件。
  3. 弹出识别报告，例如：
    识别到 9 段墙、1 扇门、1 扇窗、2 个房间。
    将替换当前户型并清空家具（可撤销）。
  4. 确认后，户型替换为导入的图纸，家具、拆墙记录和测量线清空，画面自动缩放到新户型，提示「户型已导入」。
  5. 不满意可以 Ctrl+Z 撤销，回到导入前的方案。

识别规则

  • 房间：墙围出的封闭区域就是房间，面积小于 1 m² 的区域（墙缝、管井）会被丢掉。
  • 房间名：取落在区域里的文字；没有文字的区域叫「未命名房间」，可以在右侧面板改名。
  • 默认地面：按房间名猜一个材料，之后可以随时更换。
  • 外墙：一侧是室外的墙自动标为外墙，其余为非承重墙。所有墙默认都不是承重墙，需要手动标记（见下一节）。
  • 入户门：一侧是室外、且离户型外边最近的门。
  • 窗：窗台高 0.9 m，窗顶高 2.4 m。
  • 门：推拉门和平开门无法区分，一律按平开门处理。
房间名包含默认地面
卫、浴、厕、洗衣、阳台300 防滑砖
厨600 地砖
卧、房、书、儿童橡木地板

导入后的尺寸标注只画户型外框的总长和总宽，不画内置户型那样的分段尺寸链和「入户」箭头。

识别报告里的警告

有下面这些情况时，确认框会多出几行提示，仍然可以选择继续导入。

提示原因怎么处理
跳过 N 条斜线WALL 图层有偏离水平或竖直超过 1° 的线。斜墙不支持。可以在 CAD 里改成正交墙，或者接受这段墙缺失。
N 条墙线未配对有单线找不到间距 60–500 mm 的平行线。检查是否漏画了墙的另一条边线，或者 WALL 图层混进了其他线。
N 个门窗未对上墙DOOR 或 WINDOW 图层的图形没有落在任何墙上。检查门窗图块的位置，确保它覆盖在墙线上。
N 个房间未命名有封闭区域里没有 TEXT 文字。导入后在右侧面板给房间改名，或者在 CAD 里补上文字。
N 处疑似墙线缺口某个没有房间名的区域漏到了室外，墙线可能没有闭合。在 CAD 里检查那一圈墙线，补上缺口再导入。

无法导入的情况

提示原因怎么处理
无法读取该 DXF 文件文件不是 ASCII DXF，例如 DWG、二进制 DXF，或改了扩展名的其他文件。在 CAD 里另存为 ASCII DXF。
未在 WALL 图层找到墙线没有名为 WALL 的图层，或者图层里没有能配对成墙的双线。把墙线移到 WALL 图层。
墙线可能存在缺口，请检查 WALL 图层是否闭合某个房间名落在了室外，说明它所在的房间没有被墙围住。找到这个房间，补上墙线缺口。

出现这些提示时，当前方案保持不变。

标记承重墙

DXF 图纸一般不区分承重墙，导入后所有墙默认都不是承重墙，需要手动标记。这个功能只对导入的户型开放，内置户型的承重墙已经画好。

  1. 确认当前是 选择 工具（按 V）。
  2. 在平面图上点一段墙，右侧面板显示这段墙的类型、长度、厚度，以及 DXF 识别出的类型。
  3. 点 标记为承重墙，墙变成黑色，提示「已标记为承重墙」。
  4. 再点一次 取消承重墙标记，墙恢复为 DXF 识别出的类型（外墙或非承重墙）。
  • 承重墙用拆墙工具拆不掉，会提示「承重墙（黑色）不可拆除」。
  • 如果这段墙之前已经标记拆除，标成承重墙时会自动恢复。
  • 标记可以用 Ctrl+Z 撤销，随方案一起保存和导出。
内置户型内置户型的墙在选择工具下点不中，点到的是墙旁边的房间或背景。要查看哪些是承重墙，打开顶栏 承重墙 图层。

常见问题

3D 场景一直是空白？
第一次进入 3D 需要从 jsDelivr 加载 Three.js，请确认网络能访问 cdn.jsdelivr.net，然后刷新页面。
我的图纸是 DWG，怎么导入？
在 AutoCAD 或其他 CAD 软件里用「另存为」选择 DXF 格式（ASCII），再导入。
导入后房间名是乱码？
程序会自动识别 UTF-8 和 GBK。如果还是乱码，在 CAD 里用较新的 DXF 版本（如 AutoCAD 2007 及以上）重新导出。
导入后少了一个房间？
通常是这个房间的墙线没有闭合，它和室外连在了一起。看看识别报告里有没有「疑似墙线缺口」，在 CAD 里补上缺口再导入。
斜墙、弧形墙怎么办？
目前只支持水平和竖直的墙，斜墙会被跳过，并在识别报告里列出条数。
推拉门显示成了平开门？
图纸里推拉门和平开门无法区分，导入时一律按平开门处理。
换了浏览器，方案不见了？
方案只保存在原来那个浏览器里。回到原浏览器导出 JSON，再在新浏览器里导入。
怎么回到内置户型？
文件 ▾ → 重置为默认方案。如果刚导入完，直接 Ctrl+Z 也可以。
